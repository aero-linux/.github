# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x (Supernova) | :white_check_mark: |
| < 1.4.0 | :x:                |

## Reporting a Vulnerability

The Aero Linux Project takes systems security, kernel hardening, and local sandboxing seriously.

To report a vulnerability:
1. Please email the lead architect directly at **ronitgupta138@gmail.com** with the subject `[SECURITY] Aero Linux Vulnerability Report`.
2. Include full reproduction steps, affected CLI module or GTK3 app, and system details.
3. We will acknowledge receipt within 24 hours and coordinate a security advisory and patch.
