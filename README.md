### 🤝 Contributing & Community Governance

We welcome RFCs, issue reports, and pull requests from systems programmers, Linux kernel enthusiasts, and full-stack developers.

1. **Review open issues:** Check roadmap tasks or propose architectural RFCs.
2. **Coding Standards:** Follow first-principles design — zero telemetry, minimal dependencies, and full test suite verification (`make test`).
3. **Packaging:** Verify Debian builds using `make deb`.
